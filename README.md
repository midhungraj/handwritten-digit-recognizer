
# MNIST CNN with PyTorch

A simple Convolutional Neural Network built with **PyTorch** to classify handwritten digits from the **MNIST dataset**.

## App

## Run

Train the model:

```bash
python train.py
```

Run prediction:

```bash
python predict.py
```

## Dataset

This project uses the [MNIST](https://en.wikipedia.org/wiki/MNIST_database) handwritten digit dataset.
