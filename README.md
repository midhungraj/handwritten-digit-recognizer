
# Handwritten Digit Recognizer

A simple handwritten digit recognition application built with Python, Tkinter, and PyTorch.

Draw a digit using your mouse, and the trained CNN model predicts the digit.

## Run

Train the model:

```bash
python train.py
```

Run prediction:

```bash
python app.py
```

## Dataset

This project uses the [MNIST](https://en.wikipedia.org/wiki/MNIST_database) handwritten digit dataset.
